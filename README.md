Weather App

Description

A simple Weather App built using HTML, CSS, and JavaScript also We’ll use the *OpenWeatherMap API* to fetch real-time weather data and display temperature, humidity, wind speed, and weather icons dynamically.  

Features

Search functionality to find weather data for specific cities.  
Displays real-time temperature.  
Shows additional weather details like humidity and wind speed.  
Clean user interface with dynamic weather icons and a gradient background.  

Technologies Used

HTML,CSSJavaScript

How to Run

Download or clone this repository.
Open index.html in your web browser.
